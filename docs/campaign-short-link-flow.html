Campaign Short Link — Kaise kaam karta hai

Frontend (Netlify) + Backend (Render) + MongoDB — click tracking ka poora flow, simple bhasha mein.

1. Ek line mein samjho

Aap ek lamba link (jaise Myntra ka UTM wala link) dete ho → backend uska ek chhota link bana deta hai → jab koi us chhote link ko kholta hai, request pehle aapke backend par aati hai → backend click save karta hai → phir visitor ko asli Myntra link par bhej deta hai (302 redirect).

Golden rule: click sirf tab track hota hai jab request aapke backend se hokar guzre. Isliye hamesha short link share karo, "Redirects to" wala lamba link nahi.

Campaign info (industry, utm_source, medium, campaign)Campaign se copy hoti hai — taaki analytics fast ho

Kya count nahi hota

  • Bots — WhatsApp / Facebook / Slack ka link preview, Google crawler, curl, Postman. Ye save hote hain par bot_clicks mein alag, asli clicks mein nahi.
  • Paused / expired / abhi start nahi hua campaign — visitor fallback_url par jaata hai (ya "link inactive" page), click count nahi hota.
  • Archived (delete kiya) campaign — 404 page. Naam hamesha reserved rehta hai, koi dusra use nahi le sakta.

6. Campaign banane ka flow (admin side)

  1. Frontend form kholta hai → GET /campaigns/industry-types se dropdown bharta hai.
  2. Aap short name type karte ho (jaise nikhilcampaings) → frontend har 400ms par GET /campaigns/check-slug?slug=… bhejta hai. Naam liya hua hai to "already taken — please change the short URL name" aur 3 suggestions dikhte hain.
  3. Submit → POST /campaigns. Backend UTM params jod kar final_url banata hai aur MongoDB mein save karta hai.
  4. Response mein short_url aur short_url_path aate hain → UI copy button + QR code dikhata hai.
  5. Aap short link Instagram / WhatsApp par share karte ho → clicks aane lagte hain → analytics page par dikhte hain.

7. succesly.in/r/… chalane ke liye (Netlify rule — DNS change nahi)

Frontend repo mein public/_redirects file ki sabse pehli line (SPA wale /* /index.html 200 se upar):

/r/*  https://api.succesly.in/r/:splat  302

Ya netlify.toml mein:

[[redirects]]
  from   = "/r/*"
  to     = "https://api.succesly.in/r/:splat"
  status = 302
  force  = true

Render env mein SHORT_LINK_PATH_BASE_URL=https://succesly.in rakho taaki UI yahi link dikhaye. Frontend redeploy karo — ho gaya.

api.succesly.in ko kuch nahi chhedna — ye rule sirf request ko wahan bhejta hai.

8. nikhilcampaings.succesly.in chalane ke liye (wildcard DNS)

  1. Render → service darkdeep-learning-001 → Settings → Custom Domains → *.succesly.in add karo. Render jo DNS records dikhaye (khaas kar _acme-challenge) note karo.
  2. Netlify → Domains → succesly.in → DNS records → Add: CNAME, name *, value darkdeep-learning-001.onrender.com. Saath mein Render wala _acme-challenge record bhi.
  3. Render par Verify → SSL certificate banne do (kuch minute).
  4. Check: nslookup test123.succesly.in 8.8.8.8 IP dikhaye to ready.
succesly.in, www aur api ke existing records waise hi rahenge — DNS mein specific record hamesha wildcard se pehle match hota hai. Code mein www, api, administration jaise naam reserved hain.

10. Aksar pooche jaane wale sawaal

Localhost par subdomain kyun chal jaata hai, live par nahi?

Browser *.localhost ko apne aap aapke computer par bhej deta hai — DNS ki zaroorat nahi. Internet par har subdomain ke liye DNS record chahiye, isliye live par section 8 karna padta hai.

"Redirects to" wala Myntra link copy karke share karun to track hoga?

Nahi. Wo link seedha Myntra ke server par jaata hai — aapke backend ko pata hi nahi chalta. Sirf short link track hota hai.

Kya kisi aur ka domain (jaise abc.com) use kar sakte hain?

Nahi. Domain ka DNS sirf owner badal sakta hai. Apna domain (succesly.in) use karo, ya ek chhota naya domain khareed lo.

Backend aur frontend dono deploy karne padte hain?

Tracking ke liye sirf backend zaroori hai. Frontend sirf campaign banane / analytics dekhne ka UI hai — tab tak Swagger (/api-docs1) se bhi kaam ho sakta hai.

Same visitor 5 baar click kare to?

Total clicks 5, unique clicks 1 — _cvid cookie se pehchana jaata hai. Cookie delete ki ya dusra browser/phone liya to naya visitor gina jaayega.
